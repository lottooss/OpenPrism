# Contributing to OpenPrism

Open an issue describing a reproducible problem or proposed improvement. Keep changes focused, preserve public contracts, and include tests and documentation.

Run the build, tests, lint and type checks described in README.md before submitting a pull request. Do not include credentials, machine-specific configuration, model weights, engines, raw datasets or private recordings.

Contributions are accepted under the project license. Preserve all third-party notices. Do not add process injection, game-memory inspection, anti-cheat bypass or weakened input-safety checks.
